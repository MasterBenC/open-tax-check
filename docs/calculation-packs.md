# 税额计算规则包

OpenTaxCheck 的计算规则包用于客户内部《税务健康检查报告》，不是自动申报器，也不替代客户对事实和资料完整性的确认。

## 当前正式覆盖

- 全国 20 个税费项目均已内置 2023–2026 年适用性筛查包。
- 增值税已按 2026-01-01《增值税法》施行日拆分为两个正式计算期间包，覆盖一般计税 13%、9%、6% 和有证据确认的符合条件小规模 1% 路径。一般计税按不含税销售额乘税率后减允许抵扣进项税额；小规模路径强制要求进项抵扣额为 0。零税率、免税、3%/5% 简易计税、差额征税、不动产及土地使用权等未覆盖路径保持待确认。
- 印花税已内置 2023–2026 年法定税目税率表，并按 2023-08-28 证券交易印花税税率调整拆成两个不可变期间包。客户确认存在应税事项后，系统继续询问法定税目和本条计税依据。
- 税目只能由客户按合同、产权转移书据、营业账簿或证券交易事实选择；AI 不得自动分类。未知税目不会使用默认税率。
- 跨税率变更期间且所选税目税率发生变化时，必须拆分期间和计税依据后分别计算。
- 契税已内置 2023–2026 年正式计算包，但具体适用税率仍须由客户按省级政策确认并绑定证据。程序会强制校验 3%–5% 法定幅度，超出范围立即阻断；不会自行选择税率或套用减免。
- 城市维护建设税按客户确认的所在地类别选择 7%、5% 或 1%；教育费附加和地方教育附加的标准比例分别为 3% 和 2%。三者均包含 2023–2026 年符合条件经营主体的减半征收路径，优惠资格必须有证据；计征基础必须是客户依据申报、实缴、减免、留抵退税和进口排除口径确认后的金额。
- 企业所得税已覆盖居民企业一般税率 25%、符合条件的高新技术企业 15% 和符合条件的小型微利企业 5% 实际税负路径。小微路径强制校验 300 万元应纳税所得额上限；从业人数、资产总额、行业和资格仍必须由客户提供证据确认。其他优惠、非居民和核定征收情形保持待确认。
- 车辆购置税按客户依据取得方式确认的法定计税价格乘 10%；烟叶税按客户确认的烟叶收购实际支付价款总额乘 20%。免税、减税、价格核定或其他特殊计税情形不会自动套用。
- 房产税覆盖房产余值 1.2% 和租金收入 12% 标准路径。地方 10%–30% 原值减除幅度、征收期间和免减税情况必须先由客户依据省级政策确认；个人出租住房等优惠路径保持待确认。
- 个人所得税覆盖居民个人综合所得年度汇算路径。客户必须先确认年度应纳税所得额和居民综合所得分类，程序再按法定七级税率表自动选档并扣除速算扣除数；经营所得、非居民个人、分类所得和奖金单独计税等路径保持待确认。
- 城镇土地使用税、耕地占用税、车船税、环境保护税和船舶吨税提供“计税数量×适用单位税额”正式计算路径。客户必须确认并绑定同一税目、计税单位、期间、档次和减免口径的计税数量、单位税额及分类说明；地方具体税额、污染物分类、车船档次或吨税待遇不会由程序或 AI 自动选择。
- 资源税支持客户确认的单一从价或单一从量计算。应税产品、原矿或选矿、地方计征方式、计税单位、具体税率及减免口径必须有证据并分别核算。
- 关税按 2024-12-01《中华人民共和国关税法》施行日分段，支持客户确认的单一从价或单一从量计算。税则号列、原产地、申报日、税率类型、贸易措施和计税价格必须由客户依据海关资料确认；复合计征、反倾销、反补贴、保障、报复性关税等路径不在同一条计算中自动合并。
- 消费税支持客户已拆分并确认的单一从价或单一从量组成。产品税目、征税环节、组成计税价格、比例税率或单位税额必须有证据；卷烟、白酒等复合计税的两个组成必须分别核对后另行汇总，不能把复合结果伪装成单一参数。
- 土地增值税支持清算项目的客户确认档次计算。程序把四个增值率档次绑定为30%、40%、50%、60%法定税率，并从增值额乘税率的结果中减去客户确认的速算扣除额；项目范围、扣除项目、增值率、5%/15%/35%速算扣除系数及免税资格仍必须由客户用清算底稿证明。预征、核定征收和未清算项目不直接套用。
- 至此 20 个税费项目均至少具备一条受控计算路径，但不能据此宣称所有法定税目、优惠、地方规则和特殊情形已经完整编码。

默认命令会自动加载内置筛查包和全部内置正式计算包：

```text
opentaxcheck tax-health-check --request request.json --output-dir output
```

所有可计算事实必须标记为客户确认，并绑定合同、书据、账簿、申报表或官方政策等证据引用。一个计算记录只代表一个已确认税目或汇总行，不代表整个申报期间的全部应纳税额。

## 外部参数化规则包

自有规则包可以通过可重复的 `--pack PATH` 显式传入：

```text
opentaxcheck tax-health-check --request request.json --output-dir output --pack examples/calculation-packs/vat-cn-2023-2026.parameterized.json
```

程序会拒绝不存在、损坏、越界、symlink 或 Windows reparse point 规则包。`--include-parameterized-packs` 可一次启用全部 20 个税费项目的参数化模板；这些模板只绑定计算事实和官方来源，不提供统一法定税率，也不会覆盖内置正式规则。

## 公式与模式边界

- schema `1.2.0`：税率作为客户确认并绑定证据的事实传入。
- schema `1.3.0`：规则包可以提供经核验的法定税率表，或为客户确认的地方税率声明法定上下限。
- schema `1.3.0` 也允许由官方依据直接声明固定税率，不要求客户重复输入税率。
- schema `1.4.0`：规则包可以声明有序法定累进档位、上限、税率和速算扣除数；档位只按已确认税基自动选择。
- `generic.base_minus_deductions_times_rate.v1`：计税基础减扣除额后乘税率。
- `generic.base_times_rate.v1`：计税基础乘税率，不接受扣除额绑定。
- `generic.base_times_rate_minus_credits.v1`：计税基础乘税率后减允许抵扣税额；结果不低于零，超额进项的结转或退税仍须按资料另行确认。
- `generic.base_times_rate_minus_quick_deduction.v1`：计税基础乘法定档位税率后减速算扣除数。
- `generic.quantity_times_unit_amount.v1`：客户确认的计税数量乘适用单位税额；只有这一公式允许单位税额大于 1，百分比税率公式仍拒绝大于 100% 的参数。
- `generic.base_times_applicable_parameter.v1`：已确认计税依据乘已确认计税参数，用于既可能从价也可能从量的税种；报告不会擅自把参数格式化为百分比或单位税额。
- `generic.base_times_rate_minus_confirmed_deduction.v1`：计税基础乘法定税率后减客户确认且有证据的速算扣除额；当前用于土地增值税清算档次，不允许 AI 自行判断增值率或扣除项目。

缺少客户确认、证据、当地政策或期间拆分时，报告保留“待补充资料”“待确认当地政策”或“暂时无法判断”，不会猜测并生成税额。

## 交付边界

机器快照保留稳定英文公式 ID 和税目 selector，供 Codex、Hermes、WorkBuddy、扣子、Qoder、Claude Code、OpenClaw 等宿主审计复用；客户 Markdown、Word 和 PDF 报告显示中文税目和百分比税率。所有输出仍受免责声明约束，不构成涉税鉴证、专业税务意见或纳税申报结论。

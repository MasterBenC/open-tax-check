# AI 智能体安装与运行

## 安装

在支持终端工具的 AI 智能体中发送以下指令：

```text
请在当前项目的隔离 Python 环境中安装 open-tax-check[excel,report]，安装 Playwright Chromium，运行 opentaxcheck --help 验证；不要上传客户资料、不要自动确认科目分类或税务解释。安装完成后告诉我版本、安装位置和验证结果。
```

Hermes 可从 GitHub 安装当前公开版本；WorkBuddy、扣子、Qoder、腾讯 SkillHub 等商店版本应使用各自商店的签名包。商店来源只改变安装渠道，不改变确定性规则、证据合同和人工确认边界。

## 必备确认

1. `confirm-mapping`：确认选表和字段映射。
2. `confirm-account-classification`：由客户或明确授权人员确认受控科目分类。
3. `confirm-cross-check`：由客户确认差异解释并提供当前案件内可核验的证据引用。

AI 智能体可以使用自身 OCR/视觉能力读取资料并生成结构化候选内容，但不得替客户执行上述确认，不得修改固定阈值、公式、期间或检查状态。一次最多展示三项交叉核对问题。正式客户报告固定为中文 PDF；HTML、Excel 工作底稿、机器快照和证据包是内部审计产物。

科目分类合同中的确认人格式固定为 `human:<姓名或授权标识>`。这是一项可审计的人工声明，不是税务专业资质证明；没有该声明时系统拒绝保存。

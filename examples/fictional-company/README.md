# 完全虚构公司示例

本示例用于演示 OpenTaxCheck v0.1 的本地、确定性端到端流程。本示例中的公司、交易、凭证、金额、人物和结论均为完全虚构，不包含任何真实客户信息，也不得被解释为针对任何真实主体的税务意见。

示例数据和本说明随本仓库按 Apache License 2.0 许可；详情见仓库根目录的 `LICENSE`。税务筛查结果仅用于演示，必须经过专业复核，不能作为审计、鉴证、法律意见、纳税申报或税务机关认定。

序时账包含三张借贷平衡的虚构凭证：销售收入 1,000,000 元、业务招待费 20,000 元，以及摘要含“中秋礼品及高档茶叶”的办公费 5,000 元。运行后应产生：

- `CIT-BE-001`：业务招待费纳税调增 15,000.00 元；
- `SEM-EXP-001`：仅供复核的语义费用候选，不构成税务结论；
- 案件状态 `needs_professional_review`。

`--output` 必须指向不存在或空目录；runner 会拒绝非空目录，避免覆盖已有数据或混杂旧产物。runner 会把本示例的 CSV 复制到该独立案件目录，不会修改示例源数据。

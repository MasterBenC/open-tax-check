# 模型建议

模型只帮助 AI 智能体理解资料、解释问题和组织对话；税额计算、状态、证据绑定及报告结论始终由 OpenTaxCheck 的确定性引擎生成，换模型不得改变结果。

## 推荐

按能力档选，不绑定具体版本号——型号随厂商迭代，写死会很快失效：

- 首选：具备结构化 JSON 输出、文件读取和命令调用的前沿通用模型（DeepSeek、Qwen、GLM、混元、豆包、GPT、Claude 等各家当前稳定版）
- 成本均衡：同族的小一号或量化版本
- 不作为默认：预览版、实验版，以及不支持结构化 JSON 或工具调用的模型

部署前应确认宿主支持结构化 JSON、文件读取和命令调用。

## 能力降级

- 上述推荐模型且宿主工具完整：可使用 `deep`，但不得代替客户确认或机器计算。
- 未知但能稳定处理结构化 JSON 和工具调用的模型：使用 `assist`。
- 缺少结构化 JSON、文件读取或命令工具：使用 `off`，只运行确定性流程。

任何模式都必须原样展示 `case-guide/v2`、客户问题和 `tax-customer-handoff/v1`，不得自行生成更强的税务结论。

# 模型建议

模型只帮助 AI 智能体理解资料、解释问题和组织对话；税额计算、状态、证据绑定及报告结论始终由 OpenTaxCheck 的确定性引擎生成，换模型不得改变结果。

## 推荐

- DeepSeek V4
- 腾讯混元 3（Hunyuan 3）
- GLM-5.2
- GPT-5.6
- Claude 4.8+
- Qwen 3.7 Max
- Doubao Seed 2.0 Pro

`qwen3.7-plus` 可作为成本均衡方案。预览版模型不作为默认推荐；部署前应确认宿主支持结构化 JSON、文件读取和命令调用。

## 能力降级

- 上述推荐模型且宿主工具完整：可使用 `deep`，但不得代替客户确认或机器计算。
- 未知但能稳定处理结构化 JSON 和工具调用的模型：使用 `assist`。
- 缺少结构化 JSON、文件读取或命令工具：使用 `off`，只运行确定性流程。

任何模式都必须原样展示 `case-guide/v1`、客户问题和 `tax-customer-handoff/v1`，不得自行生成更强的税务结论。

# 本地知识库挂载（personal-kb）

OpenTaxCheck 的确定性引擎**不**依赖本知识库：公式、税率、状态机与交叉核对仍由 `open_tax_check` 包独自计算。本文件只约束 **AI 控制器**在解释法条、部门规章、加计扣除、高新优惠、发票或征管口径时的引用路径。私库 `MasterBenC/personal-kb` **不随本 Skill 公开发布**。

## 用途

核对或向客户解释下列内容前，先查阅已挂载的 `personal-kb/02-税务/`（`法条/`、`行政法规/`、`司法解释/`、`部门规章与规范性文件/`）：

- 税法条文与实施条例
- 发票、征管口径
- 研发费用加计扣除
- 高新技术企业税收优惠路径（资格事实仍须客户确认）

涉及股权结构、重组、激励等民商+税交汇议题时，可再打开 `personal-kb/03-交汇专题/`，并回读 `02-税务/` 单篇。**知识库缺失时不得编造条文原文、条号、文号或规章标题。**

## 宿主如何挂载

任选其一（建议优先级从上到下）：

1. 环境变量 `PERSONAL_KB_ROOT` 指向 personal-kb 仓库根（含 `_index.md` 的那一层）。
2. 与本仓库或 Skill 目录同级的 sibling 克隆：`../personal-kb`。
3. 宿主配置中声明的绝对路径。

可选二级库（**仅当用户明确要求核对高新 / 专精特新 / 单项冠军等资格政策时**再挂载；不得据此自动认定客户已具备资格）：

- `MIIT_QUALIFICATION_KB_ROOT` 或 sibling `../miit-qualification-kb` → 私库 `MasterBenC/miit-qualification-kb`。

挂载失败时：继续按引擎 `state.json` / `case-guide` 流程推进；凡拟引用具体法条或规章处，统一标记 `needs_verification`（或核验失败时的 `unavailable`），并说明「本地 personal-kb 未挂载或不可读」。

## 自定义知识库最小目录与条目格式示例

**不随本 Skill 分发任何私有知识库**；外部使用者按下述最小结构挂载自己的税法资料库（挂载方式同上文 `PERSONAL_KB_ROOT`）。未挂载、目录不可读或条目缺失时，仍严禁编造条文原文、条号、文号或规章标题，一律标记 `needs_verification`。

```text
<KB_ROOT>/
  _index.md                       # 人读索引，可为空，不作为引用依据
  02-税务/
    法条/                          # 法律
    行政法规/                      # 条例、实施细则
    司法解释/
    部门规章与规范性文件/           # 公告、通知、指引
  03-交汇专题/                     # 可选：民商与税交汇
```

单篇条目的最小格式（`02-税务/法条/企业所得税法(2018-12-29).md`）：

```markdown
---
title: 中华人民共和国企业所得税法
doc_type: 法条                     # 法条 | 行政法规 | 司法解释 | 部门规章与规范性文件
issuer: 全国人民代表大会
doc_number: 主席令第23号            # 无文号留空，不得编造
published: 2018-12-29
effective: 2018-12-29
source_url: https://flk.npc.gov.cn/  # 官方一手来源
---

## 第八条
企业实际发生的与取得收入有关的、合理的支出，包括成本、费用、税金、损失和其他支出，准予在计算应纳税所得额时扣除。
```

引用时按 `personal-kb/<相对路径>#条号` 书写并把状态限为 `kb` / `verified` / `needs_verification` / `unavailable`；只写文件名不写条号、或条号与正文对不上时，状态一律降到 `needs_verification`，不得凭目录名或记忆补文号。

## 引用状态

对从知识库读到的条文或规章，在说明中写明路径与状态：

```text
依据：personal-kb/<相对路径>#条号或标题
来源状态：kb | verified | needs_verification | unavailable
```

- `kb`：已从已挂载 personal-kb 读出；适合内部分析与草稿。中高风险或对外正式意见应再经官方源升级为 `verified`。
- `verified`：已在 [国家法律法规数据库](https://flk.npc.gov.cn) 或 [国家税务总局](https://www.chinatax.gov.cn) 等权威一手来源核验。
- `needs_verification`：尚未完成库检索或官方核验；知识库缺失或未挂载时强制使用。
- `unavailable`：核验失败或无法取得可靠来源。

## 时效与边界

personal-kb 底稿可能滞后于官方最新文本。正式对外意见、申报口径或监管回复前，须对照官方来源复核。知识库命中**不能**改变引擎公式、税率、阈值或案件状态；也**不能**单独证明客户已具备高新等税收优惠资格。
